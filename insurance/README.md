# Insurance Dataset

This dataset contains information about 1,338 people and their medical insurance charges. Each row describes one person using features such as age, sex, BMI, number of children, smoking status, and region.

The target column is `charges`, which represents the medical insurance cost. This dataset is useful for regression tasks, especially for predicting insurance charges based on personal and health-related attributes.

Main columns:

- `age` - age of the person
- `sex` - gender
- `bmi` - body mass index
- `children` - number of children/dependents
- `smoker` - smoking status
- `region` - residential region
- `charges` - medical insurance charges

Source: https://www.kaggle.com/datasets/mirichoi0218/insurance
